## Retained process contract

The personal fork contains only durable background shell tasks. It retains:

- tools `bg_run`, `bg_status`, `bg_logs`, and `bg_kill`;
- commands `/bg`, `/tasks`, `/bg-tasks`, `/bg-clear`, `/jobs`, `/logs`, and `/kill`;
- process lifecycle, bounded logs, completion notifications, EventBus delivery, telemetry, the native running-job widget, `Shift+Down`/selected dock configuration, and `Ctrl+Alt+C`.

There is no feature-selection environment variable. Dock and shell configuration remain explicit and invalid values fail loudly. The package does not perform automatic npm update checks.

## Docs workflow

```bash
npm run docs:generate
npm run docs:verify
```

`docs:verify` is read-only and deterministic. It checks frontmatter, ownership, links, generated bytes, package payload rules, and retained public registrations. Run it after the runtime source slice is stable.

## Safety

Use isolated temporary project, agent, session, HOME, and npm roots for checks. Never use a user's Pi configuration, cache, credentials, or session data. Do not use live model calls for package maintenance. Errors at package or runtime trust boundaries must remain loud and contextual.
