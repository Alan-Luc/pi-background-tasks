# Testing operations

Use task-owned temporary project, agent, session, HOME, npm cache, and config directories. Never point checks at `~/.pi/agent` or a user's npm cache.

## Focused checks

```bash
npm run build:runtime
npm run test:type-safety
npm run test:package
npm run test:docs
npm run docs:verify
npm run payload:check
```

The package gate covers host-provided Pi peers, the process entrypoint, package files, compiler/source safety guards, and payload exclusions. The docs gate checks frontmatter, ownership, links, generated bytes, public process registrations, and the package version.

Runtime changes use the narrow unit/SDK/RPC/component or scripted-provider check first. The final stable integration run may add `npm run test:full`, `npm run smoke`, `npm run test:pty`, and `npm run test:windows`. Windows-native evidence is platform-limited when run elsewhere.

`npm run test:compat` packs into an external temporary directory and smoke-loads the compiled process entrypoint on Pi 0.81.1, 0.82.1, 0.83.0, and 0.84.0 with their TypeBox versions. It downloads test dependencies from npm but does not call a model provider.

Do not run live inference or paid model calls. Completion tests should observe EventBus/notification delivery rather than poll status or logs.
